Overlay themes from `@chameleon-ui/themes` (8 official themes, free). **`line` is the visual flagship** (hairline product language: warm canvas, paper rail, type and control feel). The other seven are **quantified tribute overlays** (validated design-rules, tokens/effects/meta, S3 gzip; report: `docs/project/reports/2026-08-15-theme-quantification.md`). Switching a theme id does not reach Linear / Stripe / a mature Ant custom site. Shipping a finished look means deepening one skin, not averaging eight. Recognition rates stay `null` until a blind test — do not invent percentages. Community marketplace packs may be free or paid.

<ThemeList />

Use the navbar theme switcher. Overlays are scoped to `data-theme` on the document element.

Load overlay CSS through package `exports`; do not guess a filesystem path:

```ts
import "@chameleon-ui/themes/cupertino/css";
```

`import "@chameleon-ui/themes/dist/cupertino/variables.css"` also works (`exports["./dist/*"]`).

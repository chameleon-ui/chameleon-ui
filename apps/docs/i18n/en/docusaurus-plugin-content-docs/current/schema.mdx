Every catalog slug has a **v0.2** `contract.json`. This site renders API tables, usage, accessibility, three-end behavior, RTL, and `data-ai` from that JSON. Do not hand-copy a second props table.

## Machine entry points

| Channel | Usage |
| :--- | :--- |
| MCP | `get_contract` `{ "slug": "button" }` |
| Package export | `@chameleon-ui/components/contracts/<slug>` |
| Disk | `packages/components/src/<slug>/contract.json` |
| Design rules | MCP `get_design_rules` `{ "theme_id": "cupertino" }` → `@chameleon-ui/themes/cupertino/design-rules` |

Agent workflow: [Agent integration](./guides/for-agents.mdx).

## Schema files

Served from this site with no login:

- [component-contract v0.2](pathname:///schemas/component-contract/v0.2.json) — **current**. `$id`: `https://chameleon-ui.dev/schemas/component-contract/v0.2.json`
- [component-contract v0.1](pathname:///schemas/component-contract/v0.1.json) — archived, still readable. Breaking changes get a new path; old `$id` is not overwritten.
- [design-rules v1.0](pathname:///schemas/design-rules/v1.0.json)

The public host is not deployed from this R&D repo. The local docs site serves the same files.

## v0.2 surface agents must read

| Key | Use |
| :--- | :--- |
| `purpose` / `scenarios` / `antiPatterns` | Use or do not use |
| `props` / `variants` / `states` | API |
| `composition` | Allowed parents / children |
| `a11y` | Role, keyboard, focus |
| `responsive` | compact / medium / large |
| `rtl` | Direction and mirrored values |
| `dataAi` | `role` + `states` + `intents` (all required) |

`dataAi.intents` must be registered in `docs/ai/data-ai-vocabulary.md`. Mapping table: `docs/ai/component-contract-v0.2-mapping.md`.

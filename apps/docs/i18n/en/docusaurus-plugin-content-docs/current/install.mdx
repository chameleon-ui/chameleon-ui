## Theme CSS

Preferred (umbrella — tokens + density + `line`):

```ts
import "@chameleon-ui/react/css";
// Vue: import "@chameleon-ui/vue/css";
```

Also valid (split files):

```ts
import "@chameleon-ui/themes/line/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
```

Other homage ids work as `@chameleon-ui/themes/cupertino/css`, etc. `@chameleon-ui/themes/dist/line/variables.css` and `@chameleon-ui/tokens/dist/css/variables.css` are also in package `exports` (`./dist/*`) and resolve to the same files. Do not use an unexported path.

## Local install (before publish)

Packages are `0.1.9`; this repo does not npm publish. `workspace:*` only resolves inside a pnpm workspace. Prefer **one umbrella** for external npm apps:

```bash
cd chameleon-ui
node ./scripts/pack-external.mjs
# in the external app:
npm install ../chameleon-ui/dist-tarballs/chameleon-ui-react-0.1.9.tgz
# or:
node ./scripts/link-external.mjs --apply
npm link @chameleon-ui/react
```

Vue: `pack-external.mjs --vue` / `npm link @chameleon-ui/vue`. Legacy five-pack: `--legacy-five`. Template check: `pnpm verify:external`.

Publish plan: first git tag `v0.1.9` (owner 待指定). `pnpm publish -r` rewrites `workspace:*` to versions. Until then, do not assume `npm install @chameleon-ui/react` works from the public registry.

## External app (not a pnpm workspace)

Copy this into an **npm / yarn / standalone Vite** app. Never put `"workspace:*"` in the consumer `package.json`. Agents must follow [Agent integration](./guides/for-agents.mdx) and `chameleon-ui/AGENTS.md`, and call MCP `get_import_specifiers` before writing imports.

```tsx
import "@chameleon-ui/react/css";
import { Alert, Button, Card } from "@chameleon-ui/react";

export function App() {
  return (
    <Card>
      <Alert status="info" title="Linked" description="Chameleon UI is on the graph." />
      <Button variant="solid">OK</Button>
    </Card>
  );
}
```

Prefer `@chameleon-ui/react/css`. Split files may use `@chameleon-ui/themes/line/css` (or `@chameleon-ui/themes/cupertino/css`, etc.). Do not use the unexported `@chameleon-ui/themes/*/variables.css`. The `dist/` alias works; it is not preferred.

## Environment

Node **≥ 20.19**, pnpm **9.15.0**. Publishable packages declare `engines.node`.

## Dual track and external Vite

Pick the umbrella package (or legacy five) or `chameleon add` — not both half-done. Windows Vite (`preserveSymlinks`, `dedupe`, `fs.allow`) lives in `templates/external-vite-react` and `templates/external-vite-vue`. Full checklist: [External consume](./guides/consume.mdx).

```bash
node ./scripts/link-external.mjs --print-vite
node ./scripts/link-external.mjs --print-vite-vue
node ./scripts/pack-external.mjs
node ./scripts/pack-external.mjs --vue
```

Pin at the app root: React `react@^19` · `@ark-ui/react@5.38.0`; Vue `vue@^3.5` · `@ark-ui/vue@5.38.1`; plus `intl-messageformat@11.2.13` · `@formatjs/icu-messageformat-parser@3.5.14`. React 18 is out of range.

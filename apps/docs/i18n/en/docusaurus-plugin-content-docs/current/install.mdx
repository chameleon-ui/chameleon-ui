## Theme CSS

Preferred:

```ts
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
```

`@chameleon-ui/themes/dist/cupertino/variables.css` and `@chameleon-ui/tokens/dist/css/variables.css` are also in package `exports` (`./dist/*`) and resolve to the same files. Do not use an unexported path.

## Local npm link (before publish)

Packages are `0.1.9`; this repo does not npm publish. `workspace:*` only resolves inside a pnpm workspace. An external npm app must link **all** of `tokens`, `i18n`, `primitives`, `themes`, and `components` (React) or `tokens`, `i18n`, `primitives-vue`, `themes`, and `components-vue` (Vue). Linking only `components` / `components-vue` fails.

```bash
cd chameleon-ui
node ./scripts/link-external.mjs --apply
# in the external app:
npm link @chameleon-ui/tokens @chameleon-ui/i18n @chameleon-ui/primitives @chameleon-ui/themes @chameleon-ui/components
```

Publish plan: first git tag `v0.1.9` (owner 待指定). `pnpm publish -r` rewrites `workspace:*` to versions. Until then, do not assume `npm install @chameleon-ui/components` works from the public registry.

## External app (not a pnpm workspace)

Copy this into an **npm / yarn / standalone Vite** app. Never put `"workspace:*"` in the consumer `package.json`. Agents must follow [Agent integration](./guides/for-agents.mdx) and `chameleon-ui/AGENTS.md`, and call MCP `get_import_specifiers` before writing imports.

```tsx
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
import { Alert, Button, Card } from "@chameleon-ui/components";

export function App() {
  return (
    <Card>
      <Alert status="info" title="Linked" description="Chameleon UI is on the graph." />
      <Button variant="solid">OK</Button>
    </Card>
  );
}
```

CSS must be `@chameleon-ui/themes/cupertino/css`. Do not use the unexported `@chameleon-ui/themes/cupertino/variables.css`. The `dist/` alias works; it is not preferred.

## Environment

Node **≥ 20.19**, pnpm **9.15.0**. Publishable packages declare `engines.node`.

## Dual track and external Vite

Pick package-five or `chameleon add` — not both half-done. Windows Vite (`preserveSymlinks`, `dedupe`, `fs.allow`) lives in `templates/external-vite-react` and `templates/external-vite-vue`. Full checklist: [External consume](./guides/consume.mdx).

```bash
node ./scripts/link-external.mjs --print-vite
node ./scripts/link-external.mjs --print-vite-vue
node ./scripts/pack-external.mjs
node ./scripts/pack-external.mjs --vue
```

Pin at the app root: React `react@^19` · `@ark-ui/react@5.38.0`; Vue `vue@^3.5` · `@ark-ui/vue@5.38.1`; plus `intl-messageformat@11.2.13` · `@formatjs/icu-messageformat-parser@3.5.14`. React 18 is out of range.

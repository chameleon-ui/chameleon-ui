Three-end means **one component tree** morphs with container inline-size. It is not a palette swap and not two navigation trees swapped with `matchMedia`.

Breakpoints are tokens (`48rem` / `80rem`), not `768px` literals in component CSS. Spec: `docs/engineering/容器查询与三端规范.md`.

## Dual controllers

| Role | Component | Narrow | ≥48rem | ≥80rem |
| :--- | :--- | :--- | :--- | :--- |
| Root destinations | `Navigation` (`AppShell.navigation`) | Tab-bar form (up to 4 pins + More) | 12rem collapsible rail | 16rem persistent sidebar |
| Stack | `NavigationBar` (`AppShell.header`) | Centered title, back leading | Title leading | Same |
| Overlay | One `Dialog` | Docked | Centered | Centered |
| Density | `tokens/density.css` | comfortable, touch ≥44px | standard | compact |

`ActionSheet` is a separate action list. Do not treat it as the desktop form of Dialog. `Sidebar` and `TabBar` remain for **intentionally single-form** chrome; the three-end path must use `Navigation`. `Navbar` is site links, not AppShell stack chrome.

## App wiring

```tsx
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
import { AppShell, Navigation, NavigationBar } from "@chameleon-ui/components";

<AppShell
  header={<NavigationBar title={title} onBack={canPop ? pop : undefined} />}
  navigation={<Navigation label="Main" items={tabs} activeValue={tab} onSelect={onSelect} />}
>
  {screen}
</AppShell>
```

Importing only `tokens/css` leaves density at standard. Component CSS must not use viewport-width media queries; morphs run on the named `app-shell` container.

Switching tabs does not push. Back pops. Hook: `useTabStacks`.

## Height-chain checklist

1. `html, body, #root { block-size: 100%; }`
2. Do not set `min-block-size: 100dvh` on the shell
3. Nested previews override `block-size` / `max-block-size`
4. Follow the shell container; do not freeze a desktop grid against three-end morph

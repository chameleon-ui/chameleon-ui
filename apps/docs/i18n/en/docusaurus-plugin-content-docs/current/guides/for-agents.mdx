This is the **product specification for coding agents**. The short machine list is `chameleon-ui/AGENTS.md`. Attach notes: `docs/ai/agent-consume.md`.

Audience: an agent generating or editing UI in a **React or Vue app that is not this pnpm workspace**. Not an operator of the inner demo. React is primary. Vue is `@chameleon-ui/components-vue` (catalog 103/103 + ThemeProvider).

Packages are `0.1.9` and **not on npm**. Do not assume `npm install @chameleon-ui/components` until a registry publish.

## 1. Required order

| Step | Action | Tool / source |
| :--- | :--- | :--- |
| 1 | Resolve legal CSS / JS specifiers | MCP `get_import_specifiers` |
| 2 | Find a component by intent | MCP `search_components` with `intent` |
| 3 | Read the contract before emitting JSX for that slug | MCP `get_contract` |
| 4 | Read design rules before density, radius, or RTL | MCP `get_design_rules` |
| 5 | Disk writes only through install-core | CLI `chameleon add` or MCP `install_*` |

Do not invent import paths. Do not write `workspace:*` into a consumer `package.json`.

## 2. Attach MCP

Build the server, then configure it on the **consumer repo** (not this monorepo):

```bash
corepack pnpm@9.15.0 --filter @chameleon-ui/mcp-server build
```

Cursor `.cursor/mcp.json` or Claude Code `.mcp.json`:

```json
{
  "mcpServers": {
    "chameleon-ui": {
      "command": "node",
      "args": ["D:/ChameleonUI/chameleon-ui/packages/mcp-server/dist/index.js"],
      "env": {
        "CU_TARGET_DIR": "D:/path/to/consumer-app"
      }
    }
  }
}
```

Replace both paths. `CU_TARGET_DIR` is where `install_*` writes. Read-only tools work against the bundled catalog even if the target is empty. `npx @chameleon-ui/mcp-server` is **not** available until publish.

## 3. Tool reference

| Tool | When | Arguments | Writes disk |
| :--- | :--- | :--- | :--- |
| `get_import_specifiers` | Before any `import` | `theme_id?` `slug?` | No |
| `search_components` | “I need a submit control / tabular data” | `intent` or `query` | No |
| `get_contract` | Before emitting JSX for that slug | `slug` (or `id`) | No |
| `get_design_rules` | Before spacing, radius, or RTL | `theme_id` | No |
| `get_component` | When you need the registry file list | `id` | No |
| `list_themes` | List the 8 official themes | — | No |
| `install_with_theme` | Component + tokens + fonts + design-rules in one run | `component_id` `theme_id` | Yes |
| `install_component` | One component | `id` | Yes |
| `install_theme` | One theme | `id` | Yes |
| `install_bundle` | Component and theme as two runs. Prefer `install_with_theme` | `component_id` `theme_id` | Yes |
| `telemetry_opt_out` | Disable telemetry | — | No |
| `record_intent` | Intent vs adopt. No-op unless enabled | `intent` `adopted` | No |

`search_components` `intent` values must come from the vocabulary in `docs/ai/data-ai-vocabulary.md`. Do not invent unregistered intent strings.

## 4. Legal imports

Preferred (`preferred` from `get_import_specifiers`):

```ts
import "@chameleon-ui/react/css";
import { Button, Card, Table } from "@chameleon-ui/react";
```

Also valid (split files / other skins): `@chameleon-ui/themes/line/css`, `@chameleon-ui/tokens/css`, `@chameleon-ui/tokens/density.css`, and the underlying package `from "@chameleon-ui/components"`.

Replace the theme id with one from `list_themes`: `line` · `silver-arrow` · `stuttgart` · `corsa` · `cupertino` · `siren` · `wechat` · `ant-blue`.

Also valid (same files): `@chameleon-ui/themes/dist/line/variables.css`, `@chameleon-ui/tokens/dist/css/variables.css`.

**Never:** `@chameleon-ui/themes/cupertino/variables.css` (not exported). Importing `tokens/css` without `density.css` leaves density at standard.

Before publish, prefer **one umbrella**:

```bash
cd chameleon-ui
node ./scripts/pack-external.mjs
# consumer:
npm install ../chameleon-ui/dist-tarballs/chameleon-ui-react-0.1.9.tgz
# or:
node ./scripts/link-external.mjs --apply
npm link @chameleon-ui/react
```

Vue: `pack-external.mjs --vue` / `npm link @chameleon-ui/vue`. Legacy five-pack: `--legacy-five`.

For Windows + Vite use `templates/external-vite-react` or `templates/external-vite-vue`, or `node ./scripts/link-external.mjs --print-vite` / `--print-vite-vue`. Version matrix, height chain, ThemeProvider, dual-track: [External consume](./consume.mdx).

Optional per-slug: `import { Button } from "@chameleon-ui/components/button"` or `import { Button } from "@chameleon-ui/components-vue/button"`. Vue also: `import "@chameleon-ui/vue/css"`.

## 5. Contracts and data-ai

Every catalog slug has a v0.2 `contract.json`.

| Read via | Path |
| :--- | :--- |
| MCP | `get_contract` `{ "slug": "button" }` |
| Package export | `@chameleon-ui/components/contracts/<slug>` |
| Disk | `packages/components/src/<slug>/contract.json` |
| Schema | `https://chameleon-ui.dev/schemas/component-contract/v0.2.json` (site mirror `/schemas/component-contract/v0.2.json`) |

When emitting JSX, obey `props`, `antiPatterns`, `composition.allowedParents` / `allowedChildren`, `responsive`, `rtl`, and `a11y`.

Runtime DOM annotations come from `dataAi` (static semantics, **no PII**):

| Attribute | Source |
| :--- | :--- |
| `data-ai-role` | `dataAi.role` (= slug) |
| `data-ai-state` | current value from `dataAi.states` |
| `data-ai-intent` | `dataAi.intents[0]` |

Component pages render those fields from the same contract. Do not hand-copy a second props table.

## 6. Application chrome (dual controllers)

Native model: **one tab controller + one navigation stack per tab**. Not website chrome.

| Role | Native | Chameleon | AppShell slot |
| :--- | :--- | :--- | :--- |
| Root destinations | `UITabBarController` / BottomNavigation | **Navigation** | `navigation` |
| Stack chrome | `UINavigationBar` / Toolbar | **NavigationBar** | `header` |
| Site / marketing links | — | **Navbar** | **Forbidden** as AppShell chrome |

```tsx
import { AppShell, Navigation, NavigationBar } from "@chameleon-ui/react";

<AppShell
  header={
    <NavigationBar
      title={current.title}
      backLabel={previous?.title}
      onBack={canPop ? pop : undefined}
    />
  }
  navigation={
    <Navigation label="Main" items={tabs} activeValue={tab} onSelect={selectTab} />
  }
>
  {current.screen}
</AppShell>
```

Rules:

1. **One** `items` list. CSS morphs it from a tab bar to a 48rem rail to an 80rem sidebar. Do not mount `Sidebar` + `TabBar` for three-end chrome.
2. Switching tabs **does not push**. Each tab has its own stack. Back **pops**. Hook: `useTabStacks`.
3. Compact overflow: first 4 pins + **More**; the rest stay in the same tree and list in the sidebar form.
4. `Navbar` is for site/marketing links. Stack title and back live on `NavigationBar`.
5. Morph follows the **container** (named `app-shell`), not `matchMedia`, and not a device picker.

`Dialog` docks on a narrow container and centers when wide — still one Dialog. `ActionSheet` is a separate action list, not a Dialog morph.

## 7. SchemaRenderer

Package `@chameleon-ui/schema-renderer`. Default map is **10 slugs only**: `alert` `badge` `button` `card` `divider` `empty-state` `heading` `input` `stack` `typography`.

React: `@chameleon-ui/schema-renderer`. Vue: `@chameleon-ui/schema-renderer/vue`. `table` / `chart` / `kpi-dashboard` and the rest of the catalog import from `@chameleon-ui/react` or `@chameleon-ui/vue`, or pass a custom `map`. Do not claim full-catalog SchemaRenderer coverage.

`adapter-ag-ui` is **POC**, not supported. Do not invent `generation_quality` scores; the honest value is `null` without a configured generator.

## 8. Locales and RTL

Product copy: 21 locales — `zh-CN` `zh-HK` `ja` `ko` `ru` `hi` `en` `de` `ar` `ug` `sw` `ha` `am` `es` `fr` `pt` `bn` `id` `ur` `fa` `vi`.

RTL: `ar` `ug` `ur` `fa`. Use `directionForLocale` from `@chameleon-ui/i18n`. Do not guess `dir`.

## 9. Never

- Invent CSS specifiers that are not exported.
- Write `workspace:*` into a non-pnpm-workspace `package.json`.
- A second installer. Disk writes only via `chameleon add` / MCP `install_*` → install-core.
- Treat AG-UI as supported.
- Compose `Sidebar` + `TabBar` as a three-end Navigation.
- Use `Navbar` as AppShell stack chrome.
- Push the stack when switching tabs.
- Swap navigation trees with `matchMedia` or a device picker.

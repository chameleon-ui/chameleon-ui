來自 `@chameleon-ui/themes` 的 overlay（8 套官方主題，免費）。**`line` 是視覺旗艦**（髮絲產品語言：暖畫布、紙色側欄、字階與控件質感）；其餘七套是**已量化的致敬 overlay**（design-rules 校驗、tokens/effects/meta、S3 gzip；報告：`docs/project/reports/2026-08-15-theme-quantification.md`）。換 `theme` id 不會自動達到 Linear / Stripe / 成熟 Ant 定制站的完成度。識別率在盲測完成前保持 `null`——禁止手寫百分比。社區市場上架可以免費或付費。

<ThemeList />

使用導航欄主題切換。overlay 作用在文檔根節點的 `data-theme` 上。

應用裡載入 overlay CSS 請走包 `exports`，不要猜檔案系統路徑：

```ts
import "@chameleon-ui/themes/cupertino/css";
```

`import "@chameleon-ui/themes/dist/cupertino/variables.css"` 同樣有效（`exports["./dist/*"]`）。

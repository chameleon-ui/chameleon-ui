三端一體是 **同一棵組件樹** 隨容器 inline-size 變形，不是換色板，也不是 `matchMedia` 換兩套導航。

斷點是 Token（`48rem` / `80rem`），不是組件 CSS 裡的 `768px` 字面量。規範：倉庫 `docs/engineering/容器查询与三端规范.md`。

## 雙控制器

| 角色 | 組件 | 窄容器 | ≥48rem | ≥80rem |
| :--- | :--- | :--- | :--- | :--- |
| 根目的地 | `Navigation`（`AppShell.navigation`） | 底部欄形態（最多 4 釘 + 更多） | 12rem 可摺疊側欄 | 16rem 持久側欄 |
| 堆疊 | `NavigationBar`（`AppShell.header`） | 標題置中，返回在前 | 標題靠前 | 同左 |
| 浮層 | 同一個 `Dialog` | 貼底 | 置中 | 置中 |
| 密度 | `tokens/density.css` | comfortable，觸控 ≥44px | standard | compact |

`ActionSheet` 是獨立動作列表。不要把它當成 Dialog 的桌面形態。`Sidebar` 與 `TabBar` 仍存在，只用於 **故意單形態** 的鉻件；三端路徑必須用 `Navigation`。`Navbar` 是站點連結，不是 AppShell 堆疊。

## 應用接線

```tsx
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
import { AppShell, Navigation, NavigationBar } from "@chameleon-ui/components";

<AppShell
  header={<NavigationBar title={title} onBack={canPop ? pop : undefined} />}
  navigation={<Navigation label="Main" items={tabs} activeValue={tab} onSelect={onSelect} />}
>
  {screen}
</AppShell>
```

只引 `tokens/css` 時密度停在 standard。組件 CSS 禁止視口寬度媒體查詢；形態走命名容器 `app-shell` 上的 `@container`。

切 Tab 不 push。返回是 pop。鉤子：`useTabStacks`。

編碼 Agent 的完整規則見 [編碼 Agent 整合](./for-agents.mdx)。

来自 `@chameleon-ui/themes` 的 overlay（8 套官方致敬主题，免费）。**`line` 是视觉旗舰**（发丝产品语言：暖画布、纸色侧栏、字阶与控件质感），其余七套仍是致敬 overlay。换 `theme` id 不会自动达到 Linear / Stripe / 成熟 Ant 定制站的完成度；要「出片」需要在选定主题上深耕，而不是八套平均浅描。项目所有者已确认可作官方主题出货；禁止宣称可被认出的比例。社区市场上架可以免费或付费。

<ThemeList />

使用导航栏主题切换。overlay 作用在文档根节点的 `data-theme` 上。

应用里加载 overlay CSS 请走包 `exports`，不要猜文件系统路径：

```ts
import "@chameleon-ui/themes/cupertino/css";
import { ThemeProvider } from "@chameleon-ui/components";

<ThemeProvider theme="cupertino" locale="zh-CN">
  {app}
</ThemeProvider>
```

单主题：静态 import 一份 CSS。多主题：把 raw CSS 交给 `overlays`，只切换 `data-theme`，不要预载八份 `:root`。详见 [外部接入](./guides/consume.mdx)。

`import "@chameleon-ui/themes/dist/cupertino/variables.css"` 同样有效（`exports["./dist/*"]`）。

## 主题 CSS

推荐：

```ts
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
```

`@chameleon-ui/themes/dist/cupertino/variables.css` 与 `@chameleon-ui/tokens/dist/css/variables.css` 也已列入包 `exports`（`./dist/*`），与上面指向同一文件。不要使用未导出的路径。

## 本地 npm link（发布前）

包版本是 `0.1.0`，本仓不 npm publish。`workspace:*` 只有 pnpm workspace 能解析。外部 npm 工程必须 **全量** link：React 为 `tokens` · `i18n` · `primitives` · `themes` · `components`；Vue 为 `tokens` · `i18n` · `primitives-vue` · `themes` · `components-vue`。只 link `components` / `components-vue` 会失败。

```bash
cd chameleon-ui
node ./scripts/link-external.mjs --apply
# 外部工程：
npm link @chameleon-ui/tokens @chameleon-ui/i18n @chameleon-ui/primitives @chameleon-ui/themes @chameleon-ui/components
```

发布预案：首发 git tag `v0.1.0`（owner **待指定**）；`pnpm publish -r` 时 pnpm 把 `workspace:*` 改成版本号。在此之前不要假定 registry 上能 `npm install @chameleon-ui/components`。

## 外部工程（非 pnpm workspace）

给 **npm / yarn / 独立 Vite 应用** 复制。不要把 `"workspace:*"` 写进外部 `package.json`。编码 Agent 读 [编码 Agent 集成](./guides/for-agents.mdx) 与 `chameleon-ui/AGENTS.md`，写 import 前调用 MCP `get_import_specifiers`。

```tsx
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
import { Alert, Button, Card } from "@chameleon-ui/components";

export function App() {
  return (
    <Card>
      <Alert status="info" title="Linked" description="Chameleon UI is on the graph." />
      <Button variant="solid">OK</Button>
    </Card>
  );
}
```

CSS 用 `@chameleon-ui/themes/cupertino/css`。不要使用未导出的 `@chameleon-ui/themes/cupertino/variables.css`。`dist/` 别名可以，但不是首选。

## 环境

Node **≥ 20.19**，pnpm **9.15.0**。各可发包已声明 `engines.node`。

## 双轨与外部 Vite

整包依赖五件套，或 `chameleon add` 拷源码——先选一条。Windows + Vite 的 `preserveSymlinks` / `dedupe` / `fs.allow` 已写进仓库 `templates/external-vite-react` 与 `templates/external-vite-vue`。完整 checklist、版本矩阵、高度链与 ThemeProvider：[外部接入](./guides/consume.mdx)。

```bash
node ./scripts/link-external.mjs --print-vite
node ./scripts/link-external.mjs --print-vite-vue
node ./scripts/pack-external.mjs
node ./scripts/pack-external.mjs --vue
```

应用根钉死：React `react@^19` · `@ark-ui/react@5.38.0`；Vue `vue@^3.5` · `@ark-ui/vue@5.38.1`；另加 `intl-messageformat@11.2.13` · `@formatjs/icu-messageformat-parser@3.5.14`。React 18 不在 peer 范围。

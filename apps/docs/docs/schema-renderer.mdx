运行时包 `@chameleon-ui/schema-renderer` 把一份 JSON 编成真实组件树。它 **不是** 全 catalog 渲染器，也不是协议适配器。

仓库规范：`docs/ai/schema-renderer.md`。Agent 总则：[编码 Agent 集成](./guides/for-agents.mdx)。

## Agent 应输出的 JSON

```json
{
  "$schema": "https://chameleon-ui.dev/schemas/ui-render/v1.0.json",
  "version": "1.0",
  "root": {
    "component": "card",
    "props": { "variant": "outlined", "padding": "lg" },
    "children": [
      { "component": "heading", "props": { "level": "level-2" }, "children": ["Sign in"] },
      {
        "component": "stack",
        "props": { "direction": "column", "gap": "2" },
        "children": [
          { "component": "input", "props": { "label": "Email", "value": "", "type": "email" } },
          { "component": "button", "props": { "variant": "solid" }, "children": ["Continue"] }
        ]
      }
    ]
  }
}
```

入仓示例：`packages/schema-renderer/examples/`（`login-form.json` · `status-card.json` · `empty-results.json`）。复制到应用后再 `<SchemaRenderer schema={schema} />`。包不导出 examples 子路径。

## 默认 map（仅 10 slug）

`alert` · `badge` · `button` · `card` · `divider` · `empty-state` · `heading` · `input` · `stack` · `typography`

未知 slug 渲染为 `data-schema-error` 占位（不白屏）。深度 ≤ 32，节点 ≤ 500。

`table` / `chart` / `kpi-dashboard` / `tabs` / `grid` 以及其余 catalog **不在**默认 map。从 `@chameleon-ui/components` import，或传入自定义 `map`。不要宣称全库可渲染。

## 不是这个包

| 需求 | 去向 |
| :--- | :--- |
| 写盘安装 | install-core / `chameleon add` / MCP `install_*` |
| A2UI / MCP Apps 线格式 | 对应 `adapter-*` |
| AG-UI | `adapter-ag-ui`，**POC**，不是 supported |

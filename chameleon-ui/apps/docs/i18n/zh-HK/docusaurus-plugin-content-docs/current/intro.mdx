# Chameleon UI

MIT 許可的 React 組件，底座為 Ark/Zag。只從正式包安裝。內測 Demo 仍在 5175；本文檔站是 [http://127.0.0.1:5176](http://127.0.0.1:5176)。

本站是 **Docusaurus 3 + MDX**。API 表由每個組件的 `contract.json` 生成。文檔站**不寫盤** — `chameleon add <slug>` 只複製 CLI 命令，由 install-core 寫盤。

</div>

## 快速開始

<CopyLine code="chameleon add button" />

編碼 Agent 不要從本頁猜 import。按 [編碼 Agent 整合](./guides/for-agents.mdx) 的次序呼叫 MCP：`get_import_specifiers` → `get_contract` → 再寫 JSX。

```jsx live
function Example() {
  return (
    <Stack direction="row" gap="2" align="center">
      <Button>儲存</Button>
      <Button variant="outline">取消</Button>
    </Stack>
  );
}
```

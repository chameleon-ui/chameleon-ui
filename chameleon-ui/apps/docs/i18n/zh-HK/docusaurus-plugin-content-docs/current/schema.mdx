每個 catalog slug 有一份 **v0.2** `contract.json`。文件站的 API 表、何時用/何時不用、無障礙、三端、RTL、`data-ai` 都從這份 JSON 渲染，禁止手抄第二套。

## 機器入口

| 通道 | 用法 |
| :--- | :--- |
| MCP | `get_contract` `{ "slug": "button" }` |
| 套件匯出 | `@chameleon-ui/components/contracts/<slug>` |
| 磁碟 | `packages/components/src/<slug>/contract.json` |
| 設計紀律 | MCP `get_design_rules` `{ "theme_id": "cupertino" }` → `@chameleon-ui/themes/cupertino/design-rules` |

編碼 Agent 工作流見 [編碼 Agent 整合](./guides/for-agents.mdx)。

## Schema 檔案

本站免登入提供：

- [component-contract v0.2](pathname:///schemas/component-contract/v0.2.json) — **現行**。`$id`：`https://chameleon-ui.dev/schemas/component-contract/v0.2.json`
- [component-contract v0.1](pathname:///schemas/component-contract/v0.1.json) — 歸檔可讀。破壞性變更換路徑，不覆蓋舊 `$id`。
- [design-rules v1.0](pathname:///schemas/design-rules/v1.0.json)

公網主機尚未從本 R&D 倉部署。本機文件站提供同一份鏡像。

## v0.2 必填面

Agent 發出 JSX 前至少讀這些鍵：

| 鍵 | 用途 |
| :--- | :--- |
| `purpose` / `scenarios` / `antiPatterns` | 用或不用 |
| `props` / `variants` / `states` | API |
| `composition` | 允許的父/子 |
| `a11y` | role、鍵盤、焦點 |
| `responsive` | compact / medium / large |
| `rtl` | 方向與鏡像值 |
| `dataAi` | `role` + `states` + `intents`（三件套，均必填） |

`dataAi.intents` 必須登記在 `docs/ai/data-ai-vocabulary.md`。對映表：`docs/ai/component-contract-v0.2-mapping.md`。

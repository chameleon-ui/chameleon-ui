Chameleon UI 的一等公民是 **三端 App 殼 + Token/主題 overlay + 契約/MCP**。它還不是「今天 `npm install` 就能當 Ant Design / MUI 用」的中後台全家桶。包版本是 `0.1.0`，本倉不執行 npm publish。

官方模板：倉庫 `templates/external-vite-react`（Vite 6 + React 19）與 `templates/external-vite-vue`（Vite 6 + Vue 3），含 Windows。Catalog Vue 覆蓋 103/103（另加 ThemeProvider）。完整步驟以簡體頁與 `AGENTS.md` 為準。

## 雙軌交付（先選一條）

| 軌道 | 做法 | 何時 |
| :--- | :--- | :--- |
| **整包** | 依賴 `@chameleon-ui/components`（外加 tokens / i18n / primitives / themes） | 應用直接 import 組件 |
| **拷源碼** | `chameleon add <slug>` 或 MCP `install_*` → install-core | 要把單個組件源碼拷進自己的樹 |

不要把 `"workspace:*"` 寫進非 pnpm workspace 的 `package.json`。不要只 link `components`。

## 發布前怎麼裝

```bash
cd chameleon-ui
node ./scripts/link-external.mjs --apply
# 消費方：
npm link @chameleon-ui/tokens @chameleon-ui/i18n @chameleon-ui/primitives @chameleon-ui/themes @chameleon-ui/components
```

備選：`node ./scripts/pack-external.mjs`。Windows Vite：`templates/external-vite-react`。版本矩陣、高度鏈、ThemeProvider 見本頁簡體對應文檔 [外部接入](./consume.mdx)。

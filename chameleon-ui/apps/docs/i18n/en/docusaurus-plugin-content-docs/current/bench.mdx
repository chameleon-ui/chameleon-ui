GenUI-Bench is a local harness. Numbers come from running install-core against the live registry. This page does not invent Lighthouse or install rates. The north-star dashboard reads the same JSON.

```
corepack pnpm@9.15.0 bench:genui
```

`phase2:gates` runs the harness first, then builds the docs site, copying artifacts into `static/bench/` (HTML is `report.html` so it does not collide with the `/bench` docs route).

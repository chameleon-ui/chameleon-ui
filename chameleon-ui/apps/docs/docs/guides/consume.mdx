Chameleon UI 的一等公民是 **三端 App 壳 + Token/主题 overlay + 契约/MCP**。它还不是「今天 `npm install` 就能当 Ant Design / MUI 用」的中后台全家桶。包版本是 `0.1.0`，本仓不执行 npm publish。

适合：多端产品壳、品牌主题、Agent 可生成 UI。  
不适合的期望：企业级 Form / Table / Upload 开箱上线到 Ant Design 深度；也不要把换肤当成一线产品视觉方案。默认视觉旗舰是 `line`，内部演示默认页是产品台（`?view=street`），不是组件画廊。

官方模板：仓库 `templates/external-vite-react`（Vite 6 + React 19，含 Windows）。

## 双轨交付（先选一条）

| 轨道 | 做法 | 何时 |
| :--- | :--- | :--- |
| **整包** | 依赖 `@chameleon-ui/components`（外加 tokens / i18n / primitives / themes） | 应用直接 import 组件 |
| **拷源码** | `chameleon add <slug>` 或 MCP `install_*` → install-core | 要把单个组件源码拷进自己的树（偏 shadcn） |

不要把 `"workspace:*"` 写进非 pnpm workspace 的 `package.json`。不要只 link `components`。两条轨道都合法，混用「半套 link + 手写 workspace」会挂。

## 发布前怎么装

```bash
cd chameleon-ui
corepack pnpm@9.15.0 --filter @chameleon-ui/tokens --filter @chameleon-ui/i18n --filter @chameleon-ui/primitives --filter @chameleon-ui/themes --filter @chameleon-ui/components build
node ./scripts/link-external.mjs --apply
# 消费方：
npm link @chameleon-ui/tokens @chameleon-ui/i18n @chameleon-ui/primitives @chameleon-ui/themes @chameleon-ui/components
```

备选：`node ./scripts/pack-external.mjs` 打出五个 `0.1.0` tarball，仍不是 registry 发布。

克隆模板：

```bash
cp -R chameleon-ui/templates/external-vite-react my-app
cd my-app
npm install
npm run dev
```

## Windows + Vite（模板已写好）

真实踩坑都收进 `templates/external-vite-react/vite.config.ts`：

1. `resolve.preserveSymlinks: true`
2. `resolve.dedupe`：`react` · `react-dom` · `@ark-ui/react` · `intl-messageformat`
3. `optimizeDeps.include`：Ark + FormatJS
4. `server.fs.allow` 含 Chameleon 仓（可用 `CU_MONOREPO`）
5. **不要**把 `@ark-ui/react` alias 成目录，子路径会失效
6. CSS 用 `themes/<id>/css`、`tokens/css`、`tokens/density.css`。打印应急 alias：`node ./scripts/link-external.mjs --print-vite`

改库源码后必须先 build 对应包。消费的是 `dist`。

## 版本矩阵（钉在应用根）

| 包 | 版本 |
| :--- | :--- |
| Node | ≥ 20.19 |
| `react` / `react-dom` | `^19`（peer；不含 React 18） |
| `@ark-ui/react` | `5.38.0`（primitives 的 peer，应用根也要装） |
| `intl-messageformat` | `11.2.13` |
| `@formatjs/icu-messageformat-parser` | `3.5.14` |

按需 import：`import { Button } from "@chameleon-ui/components/button"`（`exports["./*"]`）。Barrel `@chameleon-ui/components` 仍是默认。

CSS 包声明了 `sideEffects: ["**/*.css"]`，打包器不要把组件 CSS 摇掉。

## 运行时换肤

```tsx
import { ThemeProvider } from "@chameleon-ui/components";

<ThemeProvider theme="cupertino" density="comfortable" locale="zh-CN">
  {app}
</ThemeProvider>
```

单主题：再静态 `import "@chameleon-ui/themes/cupertino/css"`。  
多主题：把各主题 raw CSS 传给 `overlays`，运行时只改 `data-theme`，不要叠八份 `:root`。

## AppShell 高度链（消费方 checklist）

1. `html, body, #root { block-size: 100%; }`（见模板 `src/index.css`）。
2. AppShell **填满父级**，不要给壳写 `min-block-size: 100dvh`。
3. 嵌套预览要覆盖 `block-size` / `max-block-size`。
4. 业务页不要写死桌面双栏 Grid 去对抗 `Navigation` 的容器查询变形。
5. 三端路径只用 `AppShell.navigation` 上的 **一个** `Navigation` `items` 列表。不要自己拼 `Sidebar` + `TabBar`。`Navbar` 不是 AppShell header。

反例：在 `#root` 里再套一层未设高度的 marketing layout，底栏会被裁掉。

## SchemaRenderer 边界

默认 map **只有 10 个 slug**：`alert` `badge` `button` `card` `divider` `empty-state` `heading` `input` `stack` `typography`。catalog 百级组件请从 `@chameleon-ui/components` import。不要宣称 SchemaRenderer 覆盖全库。

视觉回归与逐 props 试交互：文档站 playground + `internal-demo`（5175）。本仓不以 Storybook 为 SSOT。

三端一体是 **同一棵组件树** 随容器 inline-size 变形，不是换色板，也不是 `matchMedia` 换两套导航。

断点是 Token（`48rem` / `80rem`），不是组件 CSS 里的 `768px` 字面量。规范：仓库 `docs/engineering/容器查询与三端规范.md`。

## 双控制器

| 角色 | 组件 | 窄容器 | ≥48rem | ≥80rem |
| :--- | :--- | :--- | :--- | :--- |
| 根目的地 | `Navigation`（`AppShell.navigation`） | 底部栏形态（最多 4 钉 + 更多） | 12rem 可折叠侧栏 | 16rem 持久侧栏 |
| 栈 | `NavigationBar`（`AppShell.header`） | 标题居中，返回在前 | 标题靠前 | 同左 |
| 浮层 | 同一个 `Dialog` | 贴底 | 居中 | 居中 |
| 密度 | `tokens/density.css` | comfortable，触控 ≥44px | standard | compact |

`ActionSheet` 是独立动作列表。不要把它当成 Dialog 的桌面形态。`Sidebar` 与 `TabBar` 仍存在，只用于 **故意单形态** 的铬件；三端路径必须用 `Navigation`。`Navbar` 是站点链接，不是 AppShell 栈。

## 应用接线

```tsx
import "@chameleon-ui/themes/cupertino/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
import { AppShell, Navigation, NavigationBar } from "@chameleon-ui/components";

<AppShell
  header={<NavigationBar title={title} onBack={canPop ? pop : undefined} />}
  navigation={<Navigation label="Main" items={tabs} activeValue={tab} onSelect={onSelect} />}
>
  {screen}
</AppShell>
```

只引 `tokens/css` 时密度停在 standard。组件 CSS 禁止视口宽度媒体查询；形态走命名容器 `app-shell` 上的 `@container`。

切 Tab 不 push。返回是 pop。钩子：`useTabStacks`。

## 高度链 checklist

AppShell 填满**父级**，不填满视口口号。消费方必须保证：

1. `html, body, #root { block-size: 100%; }`
2. 不要给壳写 `min-block-size: 100dvh`（比父级高时会裁掉 compact 底栏）
3. 嵌套预览覆盖 `block-size` / `max-block-size`
4. 业务页跟壳的容器宽度走，不要写死桌面双栏 Grid 对抗三端变形

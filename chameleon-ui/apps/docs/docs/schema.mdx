每个 catalog slug 有一份 **v0.2** `contract.json`。文档站的 API 表、何时用/何时不用、无障碍、三端、RTL、`data-ai` 都从这份 JSON 渲染，禁止手抄第二套。

## 机器入口

| 通道 | 用法 |
| :--- | :--- |
| MCP | `get_contract` `{ "slug": "button" }` |
| 包导出 | `@chameleon-ui/components/contracts/<slug>` |
| 磁盘 | `packages/components/src/<slug>/contract.json` |
| 设计纪律 | MCP `get_design_rules` `{ "theme_id": "cupertino" }` → `@chameleon-ui/themes/cupertino/design-rules` |

编码 Agent 工作流见 [编码 Agent 集成](./guides/for-agents.mdx)。

公网主机尚未从本 R&D 仓部署。本机文档站提供同一份镜像。

## v0.2 必填面

Agent 发出 JSX 前至少读这些键：

| 键 | 用途 |
| :--- | :--- |
| `purpose` / `scenarios` / `antiPatterns` | 用或不用 |
| `props` / `variants` / `states` | API |
| `composition` | 允许的父/子 |
| `a11y` | role、键盘、焦点 |
| `responsive` | compact / medium / large |
| `rtl` | 方向与镜像值 |
| `dataAi` | `role` + `states` + `intents`（三件套，均必填） |

`dataAi.intents` 必须登记在 `docs/ai/data-ai-vocabulary.md`。映射表：`docs/ai/component-contract-v0.2-mapping.md`。

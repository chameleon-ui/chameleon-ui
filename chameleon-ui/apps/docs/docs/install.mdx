## 主题 CSS

推荐（umbrella，含 tokens + density + `line`）：

```ts
import "@chameleon-ui/react/css";
// Vue: import "@chameleon-ui/vue/css";
```

也合法（分文件）：

```ts
import "@chameleon-ui/themes/line/css";
import "@chameleon-ui/tokens/css";
import "@chameleon-ui/tokens/density.css";
```

其它致敬主题可换成 `@chameleon-ui/themes/cupertino/css` 等。`@chameleon-ui/themes/dist/line/variables.css` 与 `@chameleon-ui/tokens/dist/css/variables.css` 也已列入包 `exports`（`./dist/*`），与上面指向同一文件。不要使用未导出的路径。

## 本地安装（发布前）

包版本见 `packages/*/package.json`，本仓不 npm publish。`workspace:*` 只有 pnpm workspace 能解析。外部 npm 工程优先装 **一个 umbrella**：

```bash
cd chameleon-ui
node ./scripts/pack-external.mjs
# 外部工程：
npm install ../chameleon-ui/dist-tarballs/chameleon-ui-react-0.1.9.tgz
# 或：
node ./scripts/link-external.mjs --apply
npm link @chameleon-ui/react
```

Vue：`pack-external.mjs --vue` / `npm link @chameleon-ui/vue`。旧五包：`--legacy-five`。模板自检：`pnpm verify:external`。

发布预案：首发 git tag 与包版本对齐（今日 `v0.1.9`；owner **待指定**）；`pnpm publish -r` 时 pnpm 把 `workspace:*` 改成版本号。在此之前不要假定 registry 上能 `npm install @chameleon-ui/react`。

## 外部工程（非 pnpm workspace）

给 **npm / yarn / 独立 Vite 应用** 复制。不要把 `"workspace:*"` 写进外部 `package.json`。编码 Agent 读 [编码 Agent 集成](./guides/for-agents.mdx) 与 `chameleon-ui/AGENTS.md`，写 import 前调用 MCP `get_import_specifiers`。

```tsx
import "@chameleon-ui/react/css";
import { Alert, Button, Card } from "@chameleon-ui/react";

export function App() {
  return (
    <Card>
      <Alert status="info" title="Linked" description="Chameleon UI is on the graph." />
      <Button variant="solid">OK</Button>
    </Card>
  );
}
```

CSS 优先 `@chameleon-ui/react/css`。分文件可用 `@chameleon-ui/themes/line/css`（或 `@chameleon-ui/themes/cupertino/css` 等）。不要使用未导出的 `@chameleon-ui/themes/*/variables.css`（无 `/css` 后缀的那条）。`dist/` 别名可以，但不是首选。

## 环境

Node **≥ 20.19**，pnpm **9.15.0**。各可发包已声明 `engines.node`。

## 双轨与外部 Vite

整包依赖 umbrella（或旧五包），或 `chameleon add` 拷源码——先选一条。Windows + Vite 的 `preserveSymlinks` / `dedupe` / `fs.allow` 已写进仓库 `templates/external-vite-react` 与 `templates/external-vite-vue`。完整 checklist、版本矩阵、高度链与 ThemeProvider：[外部接入](./guides/consume.mdx)。

```bash
node ./scripts/link-external.mjs --print-vite
node ./scripts/link-external.mjs --print-vite-vue
node ./scripts/pack-external.mjs
node ./scripts/pack-external.mjs --vue
```

应用根钉死：React `react@^19` · `@ark-ui/react@5.38.0`；Vue `vue@^3.5` · `@ark-ui/vue@5.38.1`；另加 `intl-messageformat@11.2.13` · `@formatjs/icu-messageformat-parser@3.5.14`。React 18 不在 peer 范围。

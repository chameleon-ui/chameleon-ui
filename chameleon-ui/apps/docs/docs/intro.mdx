# Chameleon UI

Chameleon UI 是一套 **三端 App 壳 + Token/主题 + 契约/MCP** 的设计系统，不是 Ant Design / MUI 的中后台替代品。包版本 `0.1.9`，尚未 npm publish。

适合大胆用的：`AppShell` / `Navigation` / `NavigationBar`、主题 overlay、密度 CSS。复杂上传队列、通知队列、精细滑杆以前要自封装——现在 Toast / Button / Upload / Slider 已补到可上业务的深度，仍请先读契约。

**今天能被外人用的最短路径：** 仓库 `templates/external-vite-react`，说明见 [外部接入](./guides/consume.mdx)。

MIT 许可的 React 组件，底座为 Ark/Zag。只从正式包安装。内测 Demo 仍在 5175；本文档站是 [http://127.0.0.1:5176](http://127.0.0.1:5176)。

本站是 **Docusaurus 3 + MDX**。API 表由每个组件的 `contract.json` 生成。文档站**不写盘** — `chameleon add <slug>` 只复制 CLI 命令，由 install-core 写盘。

## 快速开始

<CopyLine code="chameleon add button" />

编码 Agent 不要从本页猜 import。按 [编码 Agent 集成](./guides/for-agents.mdx) 的次序调用 MCP：`get_import_specifiers` → `get_contract` → 再写 JSX。

```jsx live
function Example() {
  return (
    <Stack direction="row" gap="2" align="center">
      <Button>保存</Button>
      <Button variant="outline">取消</Button>
    </Stack>
  );
}
```

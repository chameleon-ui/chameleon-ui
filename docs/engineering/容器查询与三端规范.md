## 1. 断点即 Token

冻结断点（愿景 §7.1，Phase 5 §0.2）：`mobile <768px` / `tablet 768–1279px` / `desktop ≥1280px`。

| Token | 值 | 语义 |
| :--- | :--- | :--- |
| `--cu-breakpoint-mobile` | `0px` | mobile 档起点（<768px 生效） |
| `--cu-breakpoint-tablet` | `48rem` | tablet 档起点（768px @16px root） |
| `--cu-breakpoint-desktop` | `80rem` | desktop 档起点（1280px @16px root） |

- 权威源：`packages/tokens/src/core/breakpoint.json`；编译产物 `dist/css/variables.css`（CSS 变量）、`dist/tokens.json`（JS/TS 扁平表）。
- **铁律**：`packages/components*/**` 的 CSS 禁止出现视口宽度媒体查询与 `768px|1280px` 字面量。由 stylelint 自定义规则 `chameleon/no-breakpoint-literal` 在 `@media` 上拦截一切宽度/高度尺寸查询（含区间语法），在 `@container` 上拦截 px 断点字面量。`@media (prefers-reduced-motion …)`、`@media (hover: hover)` 等非尺寸查询不受影响。
- 逃逸口：`stylelint-disable` 注释 + `LEGACY-*` 单号，缺一不可（与逻辑属性 lint 同级纪律）。
- 唯一允许持有视口断点媒体查询的产物是 tokens 包生成的 `dist/css/density.css`（值由编译产物内插，见 §3）。

## 2. 容器查询白名单（container-type 策略）

**默认不全局开启 `container-type`**（避免嵌套塌陷与意外包含上下文），实行白名单制：

| 组件 | 容器元素 | 消费它的后代 | 阈值（=Token） |
| :--- | :--- | :--- | :--- |
| `app-shell` | `.cu-app-shell`（根） | `.cu-app-shell__frame` / `__nav` / `__sidebar` | 48rem / 80rem。compact 把 `__nav` 钉在 block-end，主栏 `minmax(0,1fr)` 滚动 |
| `navigation-bar` | `.cu-navigation-bar`（根） | `.cu-navigation-bar__frame` / `__title` | 48rem：窄屏居中标题，宽屏标题靠前（UINavigationBar） |
| `dialog` | `.cu-dialog__positioner`（Portal 内，fixed 满视口） | `.cu-dialog__content` | 48rem |
| `action-sheet` | `.cu-action-sheet__positioner`（同上） | `.cu-action-sheet__content` | 48rem |
| `table` | `.cu-table`（根） | `__table` / `__header` / `__cell` | 47.99rem |
| `sidebar` | `.cu-sidebar`（根） | `__label` / `__toggle-text` | 12rem（组件局部阈值，见 sidebar contract） |
| `tab-bar` | `.cu-tab-bar`（根，fixed 满宽） | `__label` | 20rem（组件局部阈值，见 tab-bar contract） |

规则：

1. 组件根容器查自身后代；**容器元素不能查询自身**，需要切换根级布局时加一层内部框架元素（如 `.cu-app-shell__frame`）。
2. 断点阈值用 rem 且等于 Token 值或其 −0.01rem 下界伴随值（`47.99rem` = 低于 tablet 档）；组件局部阈值（如 sidebar 的 12rem）必须在 contract `responsive` 里写清语义。
3. 新增白名单成员 = 改本表 + 组件 contract，走 catalog `changeLog` 纪律。
4. 未进白名单的组件禁止自行开 `container-type`；未改造组件不宣称容器驱动（§5.5「禁止宣称全量覆盖」）。

## 3. 密度阶梯与随端默认

密度三档：`compact` / `standard` / `comfortable`（缩放系数 0.875 / 1 / 1.125；控件最小高 2.25 / 2.5 / 2.75rem）。

- 随端默认值表（Phase 5 冻结）：**mobile = comfortable（触控 ≥44px）· tablet = standard · desktop = compact**。
- 机制：tokens 构建期把默认值表内插进 `dist/css/density.css`（唯一允许持有视口媒体查询的生成文件）；组件只消费 `var(--cu-density-active)` / `var(--cu-control-size-active)` / `var(--cu-touch-target-min)`。
- **app 接线**：凡 `import '@chameleon-ui/tokens/css'` 的入口必须同时 `import '@chameleon-ui/tokens/density.css'`（docs / internal-demo / theme-studio / market + poc + components 单测 setup）。只引入 `variables.css` 时 `--cu-density-active` 停在 standard，不会随断点切换。
- 显式覆盖：`<html data-density="compact|standard|comfortable">` 优先于断点默认；不新增任何组件必填 prop（U8）。
- 首个消费组件：`button`（`--sm` 高度随 `control-size-active`）。后续组件按需消费，不强制铺开。

## 4. 无容器查询环境的降级策略（§0.4 书面决议）

- 基线：Container Queries 需要 Chrome/Edge ≥105、Safari ≥16、Firefox ≥110（2023 年起全量可用）。
- 降级：**mobile-first 基态**。所有白名单组件的基样式即 compact 形态（底部面板 / 隐藏侧栏 / 紧凑留白），`@container` 只做渐进增强。不支持容器查询的浏览器忽略 `@container` 块 → 恒定渲染 compact 形态：**功能可用、触控友好，仅宽屏布局不展开**。
- hover 门控：`@media (hover: hover)` 在不支持该查询的旧环境中等同「不悬停」，触控设备不再出现悬停粘滞；全库 `:hover` 规则（button / table / link / breadcrumb）已门控。
- 未验证矩阵外环境前，文档与营销不得宣称「三端一体已完成」。

## 6. 变形规则矩阵（愿景附录 C 起步）→ `contract.responsive` 落点

| 组件 | 桌面 ≥1280 | 平板 768–1279 | 手机 <768 | 契约位置 |
| :--- | :--- | :--- | :--- | :--- |
| Dialog | 居中模态（≤32rem） | 居中模态 | Bottom Sheet | `dialog/contract.json → responsive` |
| NavigationBar | 标题靠前的工具栏 | 标题靠前 | 居中标题 + Back（上一页标题） | **`navigation-bar/contract.json`**：栈铬件，不是站点链接行 |
| Navigation | 持久侧边栏（完整 `items`，可滚动） | 可折叠侧边栏（完整 `items`） | 底部 TabBar：最多 4 个钉住项 + More；其余同一棵树上的 overflow | **`navigation/contract.json`（同一 DOM、同一 `items`）**；这是 **Tab 控制器**（UITabBarController），不是栈 |
| Table | 完整表格 | 完整表格 | 容器内横向滚动；卡片列表形态仅契约描述，演示页待排期 | `table/contract.json → responsive` |
| DatePicker | 内联日历 | 弹出面板 | 底部弹出 | **P6 才建组件**；本阶段仅冻结本行行为约定，P6 实现须与本行一致 |

消费方 API（铁律）：三端一体是 **两个控制器**，不是网站顶栏+页脚。

- **Navigation** = UITabBarController / Android BottomNavigation：根级目的地。切换 Tab **不会 push**，只换到该 Tab 自己的栈。
- **NavigationBar** = UINavigationBar / Android Toolbar：当前 ViewController 的标题、返回、栏按钮。返回是 **pop**。
- **Navbar** 是营销站链接行，禁止当 AppShell 铬件。

```tsx
<AppShell
  header={<NavigationBar title={current.title} backLabel={previous?.title} onBack={canPop ? pop : undefined} />}
  navigation={<Navigation label="Main" items={tabs} activeValue={tab} onSelect={selectTab} />}
>
  {current.screen}
</AppShell>
```

Dialog 同行已经是同一组件变形（窄屏 Bottom Sheet / 宽屏居中模态）。ActionSheet 是独立的动作列表，不是 Dialog 的手机替身。

## 7. 测试纪律（A5.3）

白名单组件必须成对提供「窄容器 + 宽视口」「宽容器 + 窄视口」证据，证明驱动源是容器而非视口：

- Playwright 层：`toolings/visual-regression/tests/container-driven.spec.ts`（`apps/internal-demo` 的 `?view=lab` 容器实验页）。
- 单元层：`packages/components/src/test/container-driven.test.tsx` 静态断言白名单组件 CSS 的容器接线（container-type 在容器元素、`@container` 作用于后代）。
- 快照 PNG 基线由 `test:update` 生成并入库；不成对不得合入（§5.5 合入检查）。

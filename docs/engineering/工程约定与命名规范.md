## 3. 分层与依赖（代码设计铁律）

```
L1  tokens / themes / i18n / contract / primitives
        ↑
L2  components / blocks / components-vue
        ↑
L4  install-core ← cli · mcp-server
        ↑
    registry · apps
```

| 铁律 | 含义 |
| :--- | :--- |
| 单向依赖 | 下层不知上层；禁止 `components` import `mcp-server` |
| L1 无框架 | `tokens`/`themes`/`i18n`/`contract` 的 `package.json` **不得**声明 react/vue/svelte |
| 契约单源 | 正文只在组件目录；`contract` 包 = schema + codegen/校验 |
| rules 单源 | 只在 `themes/<id>/design-rules.json` |
| 安装单核 | 写入磁盘逻辑只在 `install-core` |
| POC 隔离 | Ark/Base 双轨只在 `poc/*`；不得污染 `packages/components` |

包内推荐目录：

```
packages/<name>/
  package.json
  README.md
  tsconfig.json          # extends ../../tsconfig.base.json
  src/
    index.ts             # 唯一公共导出面
  dist/                  # gitignore
```

## 4. 组件包目标结构（Phase 1+；Phase 0 对照用）

```
packages/components/src/button/
  index.ts
  Button.tsx
  styles.css
  contract.json
  locales/
    zh-CN.json
    en.json
    de.json
    ar.json
  Button.test.tsx
```

| 设计点 | 约定 |
| :--- | :--- |
| API | Props 与 `contract.json` 的 props/variants **同名同枚举** |
| 样式 | 只引用 `--cu-*` Token；禁止硬编码色值（POC 可临时，D3 后收敛） |
| 方向 | 只用逻辑属性：`margin-inline-start` 等；禁用 `margin-left/right` |
| 变形 | 三端差异写进 contract 的 `responsive` / `platforms` 字段（schema 定义） |
| 文档 | Prose 由 contract 生成；CI 查漂移 |

## 10. 功能点三件套：预留 · 埋点 · 标记

每个功能点合入前，必须在阶段卡矩阵里标清三列；未写则视为 **未定义 → 不得合入主干**。

### 10.1 定义

| 类型 | 含义 | 典型落点 |
| :--- | :--- | :--- |
| **预留** | 本期不做实，但留下**稳定扩展点**（空实现、接口、目录、钩子、文档坑位），避免下期挖开重来 | `install-core` 空壳；`onInstall?` 可选钩子；contract 可选字段；adapter 目录说明 |
| **埋点** | 运行时/工具链发出的**可关闭遥测事件**（B4）；禁止采源码与密钥 | `install`、`intent_vs_adopt`、`opt_out`、`generation_quality` |
| **标记** | 给人或 Agent 读的**稳定标注**（非遥测上报） | DOM `data-ai-*`；契约字段；Registry `type`；源码 `@phase-N` / `@telemetry` 注释约定 |

### 10.2 取值约定（矩阵里怎么填）

| 符号 | 含义 |
| :--- | :--- |
| **必做** | 本阶段退出门禁相关，缺了不验收 |
| **应做** | 本阶段默认要做；个别豁免须写进报告 |
| **预留** | 只留扩展点/注释/空函数，**禁止**假实现骗人 |
| **鼓励** | 能做则做，不做不挡验收 |
| **禁止** | 本阶段明确不做（做了算 scope 膨胀） |
| **—** | 不适用 |

### 10.3 埋点事件字典（全阶段稳定名）

| 事件名 | 最早阶段 | 触发点 | 必含字段（原则） |
| :--- | :--- | :--- | :--- |
| `install` | Phase 1 | install-core 写入成功后 | item id/type、来源 cli\|mcp、匿名 session、主题 id（若有） |
| `intent_vs_adopt` | Phase 1 | 搜索/推荐后是否安装 | 意图摘要、采纳结果、反模式是否触发 |
| `opt_out` | Phase 1 | 用户关闭遥测 | 时间戳、此前是否发过事件 |
| `generation_quality` | Phase 2+（可 Phase 1 预留钩子） | 可选：生成后人工修改归因 | 仅聚合指标，无源码 |

环境变量：`CU_TELEMETRY=0|1`（默认遵循「告知 + 可关」；测试可强开）。

### 10.4 标记字典

| 标记 | 最早阶段 | 位置 | 说明 |
| :--- | :--- | :--- | :--- |
| `data-ai-role` | Phase 1 鼓励 / Phase 3 必做 | 组件根 DOM | 如 `button`、`dialog` |
| `data-ai-state` | 同上 | 组件根 DOM | 可见状态摘要 |
| `data-ai-intent` | Phase 3 应做 | 可选 | 业务意图 |
| `cu-*` class | Phase 0 | DOM class | 样式与测试钩子，**不是**遥测 |
| contract 字段 | Phase 0 schema / Phase 1 正文 | `contract.json` | 给人/AI 读的语义，不上报 |
| `// @phase-N` | 任意 | 源码 | 标明「此预留给 Phase N」 |
| `// @telemetry:hook` | Phase 0–1 | install-core | 标明日后埋点挂载点 |
| Registry `type` | Phase 1 | registry item | `registry:ui` \| `theme` \| `rules`… |

### 10.5 预留写法（防假实现）

```ts
/** @phase-1 @telemetry:hook — Phase 0 仅占位，禁止在此发事件 */
export type TelemetryHook = (event: string, payload: Record<string, unknown>) => void
export const telemetryHook: TelemetryHook | undefined = undefined
```

README 必须写：「预留 / 未实现」，禁止对外演示成已具备回流能力。

### 10.6 阶段总览（细节以各 Phase §「预留·埋点·标记」为准）

| 能力域 | P0 | P1 | P2 | P3 | P4 |

| Token/lint/schema | 预留主题/公开 URL；埋点禁止 | 沿用 | schema 公开标记 | rules schema | 上架检测标记 |

## 11. 性能指标与预算（全阶段）

> 数字来源：《软件/平台设计概要》§8.1；变更须改概要并同步本表与各 Phase §5.6。

## 12. 算法、复杂度与可用性要求（底层必读）

> **结论先说**：底层（Token 编译、契约校验、安装解析、焦点/键序、Registry 检索、rules 校验等）**都会用到算法**；不是「可写可不写」。  
> 合入带非平凡逻辑的代码时，必须同时满足：**复杂度上限** + **可用性（含 a11y）要求** + **书面复杂度说明**。

### 12.1 哪里会用到算法（按层）

| 层 | 典型算法/逻辑 | 说明 |
| :--- | :--- | :--- |
| L1 tokens | 图/依赖展开、路径展平、引用解析、确定性排序输出 | 编译期；须可重复 |
| L1 themes / rules | Schema 校验、规则匹配、冲突检测 | 校验失败要可读 |
| L1 i18n | 字典加载、键查找、ICU 选择（plural/select） | 热路径查找要快 |
| L1/L2 primitives | 焦点陷阱、Roving Tabindex、类型ahead、Dismiss 层叠 | Headless 核心；优先用基元库，自研须达标 |
| L2 components | 派生状态、列表过滤（轻量）、RTL 逻辑属性（**禁止**运行时镜像整树） | 交互可预测 |
| L3/L4 contract | JSON Schema 校验、索引构建 | 可离线 |
| L4 install-core | 依赖解析、文件规划、冲突检测、幂等写入 | 安全优先于炫技 |
| L4 registry / MCP | 搜索/过滤/排序；意图匹配（可朴素） | 规模变大再索引 |
| Bench / 市场 | 聚合、抽样、上架检测流水线 | Phase 2+ |

### 12.2 算法复杂度预算（默认上限）

记号：`n` = 主输入规模（token 条数 / 文件数 / 可聚焦节点数 / 注册条目数等），须在函数注释写明。

| ID | 场景 | 时间复杂度上限 | 空间 | 强制要求 |
| :--- | :--- | :--- | :--- | :--- |
| **C1** | Token 单次完整编译 | **O(n log n)**（允许排序）；禁止指数级 | O(n) | 同输入 → 同输出（确定性） |
| **C2** | Token/CSS 单条引用解析 | 摊还 **O(1)**～**O(d)**（d=引用深度，d≤32） | O(d) | 环引用必须报错，禁止死循环 |
| **C3** | i18n 键查找（热路径） | **O(1)** 期望（Hash/Map） | O(n) 字典 | 禁止每次全表扫描 |
| **C4** | 焦点陷阱内 Tab 循环 | **O(k)**（k=可聚焦元素数） | O(k) | 不得每键击全 DOM `querySelectorAll` 无缓存策略 |
| **C5** | Roving tabindex 方向键 | **O(k)** | O(1)～O(k) | 行为符合 WAI-ARIA APG |
| **C6** | install 依赖解析（MVP） | **O(e+v)** 图遍历量级 | O(v) | 环依赖失败；禁止静默丢文件 |
| **C7** | Registry 线性搜索（≤500 条） | **O(m)** 可接受 | O(1) | 超过阈值须改索引并开讨论会 |
| **C8** | Registry 索引搜索（>500 或 Phase 2+） | 查询 **O(log m)** 或倒排摊还更优 | O(m) | 建索引可 O(m) |
| **C9** | design-rules / contract 校验 | **O(n·r)**（n 节点，r 规则）可接受 | O(n) | 错误路径定位到字段 |
| **C10** | 伪本地化/膨胀检测 | **O(n)** | O(n) | CI 可分钟级完成 |
| **C11** | 列表虚拟化（若引入） | 滚动 **O(可见数)** | O(可见数) | Phase 1 基础 Table **不要求**虚拟化 |
| **C12** | 禁止类 | 无界回溯正则、主线程同步 >50ms 的盲扫全仓、浏览器里跑完整 Token 编译 | — | 违规须改设计 |

### 12.3 可用性要求（Usability + a11y，与算法绑定）

算法再快，交互不可用也不算过。下列为**默认可用性门禁**（与体积预算并列）：

| ID | 域 | 要求 | 起控 |
| :--- | :--- | :--- | :--- |
| **U1** | 标准 | 目标 **WCAG 2.1 AA**；自动+关键路径人工 | P1 组件起；P2 发版 |
| **U2** | 键盘 | 核心任务可纯键盘完成；无键盘陷阱（焦点陷阱除外且 Esc 可出） | P0 POC 记；P1 门禁 |
| **U3** | 焦点 | Dialog/Popover 打开聚焦、关闭归还；顺序合理 | P0 对比；P1 必做 |
| **U4** | 触控 | 适用控件命中区 **≥44×44px** | P1 |
| **U5** | 键程 | 常见任务（打开 Dialog 并关闭、提交前 Tab 完主字段）≤ **约定步数**（默认主路径 ≤8 次有意义键击，不含输入字符） | P1 抽检 |
| **U6** | RTL | 逻辑属性；读顺序与镜像符合 locale；禁止「只缩放不镜像」冒充 RTL | P0 演示；P1 ar 回归 |

| **U9** | 错误可读 | 校验/安装/编译失败信息含：**路径 + 原因 + 下一步** | P0 Token/schema；P1 install |

### 12.4 算法选型原则（底层）

1. **能编译期做的，不放到运行时**（呼应 E1）。  
2. **能用经过 a11y 验证的 Headless 算法，不自研焦点/选择**（O1 选定后遵守）。  
3. **先正确可测，再谈微优化**；优化须有前后对比或复杂度证明。  
4. **确定性**：同一仓库状态 → 同一 Token/Registry 产物（禁止依赖随机/时钟除非写入版本元数据）。  
5. **失败可见**：环引用、冲突、无权限写入必须失败，禁止部分成功装瞎。

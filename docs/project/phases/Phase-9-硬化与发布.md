## 3. 怎么做（关键路径）

### 3.1 R1–R3 实测（关闭 LEGACY-2026-001…003）

1. 口径冻结：中端安卓基线（4×A76 级 + 4GB）+ Fast 4G 节流；套件页 = S5 同一页面（AppShell + common-10）。
2. 执行：`perf:lhci` 从桩改为真实测量（本地 headless 或云 LHCI，依托管决议）；JSON 入 `benchmarks/`、md 入 `docs/project/reports/`。
3. 不达标处理：超标 → 优化或 `LEGACY-*` 续期 + owner + ETA；**禁止**调宽预算冒充达标，禁止手写分数。

### 3.2 VPAT 正式

1. 人工审计：关键路径 AT 会话 + 全组件抽检；证据归档。
2. 文档：`apps/docs/public/compliance/VPAT-ChameleonUI-v<version>.pdf`（命名沿用 Phase 4 §5）；状态 `draft → published`。
3. 差距公示：未过项写 Supports with exceptions 并附 `LEGACY-*`。

### 3.3 npm publish 路径

1. `publish:check` 已有——本阶段补齐真实首发：非 private 包版本冻结（发布会定 `0.x` / `1.0.0`）、tag、provenance。
2. 安装说明三种通道（npm / Registry / MCP）在干净环境复跑取证。
3. chameleon-ui.dev 托管：决议执行或书面延期。

### 3.4 文档 21 语深度

1. 关闭 LEGACY-2026-004（chrome/页面骨架）、LEGACY-2026-005（营销页）、LEGACY-2026-017（contract 正文英文）。
2. 缺口表（`Phase-4-文档21语缺口表.md`，315 格）：目标全绿；未绿格必须有 ETA + owner，禁止整页骨架冒充译文。
3. 质量：德语膨胀 35% 与伪本地化 CI 对文档站同样生效；ug/sw/ha/am 母语审校记录入库。

### 3.5 主题盲测

执行：方法（样本量、界面池、统计口径）先于结果公布；或书面放弃并维持「不宣称」。二选一，禁止暧昧。

## 13. 风险与诚实边界（第二期总收口）

- **R1–R3**：测量环境未就绪（托管决议未落地）时，本阶段可交付「本地口径实测」但必须写明口径差异；仍禁止任何无测量分数。
- **VPAT**：无第三方时交付内部审计版 published，并注明审计方身份；禁止暗示认证。
- **npm publish**：首发后撤回成本极高；版本策略未冻结前不执行。
- **口号**：核对表任何一行无证据即降级表述（如「三端一体」缺容器查询降级验证则写「三端支持（降级策略验证中）」）。
- 本阶段结束仍有未绿项时：转运营期 `LEGACY-*` 清单 + 移交单，不以「第二期完成」名义掩盖。

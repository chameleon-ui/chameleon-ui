## 更新内容（中文）

### 1. line 旗舰视觉与核心 token（自 0.1.0 切割带入）

- 加深 **line** 为产品旗舰观感：暖色画布、纸质轨、细线 chrome；AppShell 主区去掉脚手架网格感。
- 核心 token：space **4–6**、`fg.muted`、motion 时长/缓动、字体 tracking/weight。
- 抛光 Button、Card、AppShell、Navigation、NavigationBar、Input、EmptyState、Toast、Typography、Heading 等，使 street 演示读起来像产品而非组件橱窗。

### 2. street ProductStudio 与滚动修复

- `internal-demo` 默认进入 street **ProductStudio**（`?view` 省略）。
- AppShell：父级填满、`overflow` 收敛、**单主滚动条**（稳定 gutter），避免双滚动条或挤压紧凑导航。

### 3. Vue 103/103 + 消费路径 + 官方模板

- `@chameleon-ui/components-vue`：**103/103** 目录对齐（ThemeProvider 为额外导出，非 catalog slug）。
- 消费路径修复：Vue per-slug `exports['./*']`、Toast Toaster/createToaster、Button 类型与 `data-ai-intent`、Input/Field、`@chameleon-ui/schema-renderer/vue`、MCP 说明、官方模板默认 `theme=line`、修复 Vue 模板双挂载等。
- 官方模板：`templates/external-vite-vue`（与 React 模板并列）；`verify:external` 覆盖两边 typecheck/build。

### 4. 主题工程量化（七套致敬可度量）

- 补齐致敬主题的 surface / fg / border / motion 等叶子，使 Theme Studio / 消费路径完整，**不把致敬主题改造成第二旗舰**。
- 报告：[`2026-08-15-theme-quantification.md`](./2026-08-15-theme-quantification.md) — S3 gzip + design-rules 清单；**`recognition_rate=null`**（可度量工程缺口，≠ 一眼认出率）。

### 5. 盲测操作包（PROTOCOL-READY，无假比率）

- Harness 导出、`demo:blind` / `blind:validate` / `blind:ingest`；pending 结果 `status=not_run`、`rate=null`、`pipelineStatus=ready_for_humans`。
- A9.5：**PROTOCOL-READY**（非 waive）。禁止在商业叙事中写「一眼认出 ≥80%」直至合格人工汇总存在。
- 见 [`2026-08-15-blind-test-operator-kit.md`](./2026-08-15-blind-test-operator-kit.md)、[`A9.5-盲测决策-PROTOCOL-READY.md`](./A9.5-盲测决策-PROTOCOL-READY.md)。

### 6. A11y CAB 提交包（无假证书）

- 提交包 + 证据 JSON + blocker 说明；scoped axe 证据与可修对比度/ARIA/demo 缺陷处理。
- VPAT：**draft / published-internal**；`commercialClaimsAllowed=false`；**不是**第三方 CAB 认证。
- 见 [`2026-08-15-a11y-cab-submission-pack.md`](./2026-08-15-a11y-cab-submission-pack.md)、[`Phase-9-VPAT-status.md`](./Phase-9-VPAT-status.md)。

### 7. 外部接入一等公民

- `pnpm verify:external` / `verify:external:build`；CI 可挂。
- `link-external` / `pack-external` 为注册表前主路径（含 Windows `npm.cmd` spawn 修复）。
- React / Vue 官方 Vite 模板版本钉在 **0.1.9**；React 模板 typecheck 恢复为 `tsc --noEmit`。

### 8. 版本

- 全 workspace 可对齐包从 `0.1.0` → **`0.1.9`**（含 apps、templates、poc、tooling 等既有惯例）。
- SchemaRenderer 默认 map 仍为 **10 slugs**；`adapter-ag-ui` 仍为 POC。

## Source / 源码如何拿到

### 推荐：整仓源码 zip（本机产物）

```bash
cd chameleon-ui
pnpm pack:source
# 或: node ./scripts/pack-source.mjs
```

产物路径（默认，已加入 `.gitignore`，需本地生成）：

`chameleon-ui/dist-release/chameleon-ui-0.1.9-source.zip`

排除：`node_modules`、`.tmp-chrome-audit`、`.idea`、常见 build 缓存等。内容为 **tracked 源码树**（`git archive`），不是 opaque-only dist。

### 其它方式

| 方式 | 说明 |
| --- | --- |
| `git checkout v0.1.9` | 完整可构建 monorepo |
| `npm pack` / `pack-external` | 各包按 `package.json` `files` 打 tarball；**带 src 的包**：`components`、`components-vue`、`blocks`；多数其它包仅 `dist` + README/LICENSE |
| 克隆后读 `packages/*/src` | 主题 design-rules、token 源等在仓库 `src` 中，即使得包未打进 npm `files` |

It carries **line** flagship depth and the street ProductStudio/scroll fix from the unpublished **0.1.0** cut, and adds **Vue 103/103** + consume fixes + official Vue template, **theme quantification** (rates `null`), **blind-test operator kit** (PROTOCOL-READY), **A11y CAB submission pack** (no fake cert), and first-class **verify/pack/link** templates.

**npm:** not published — blocked on 2FA / granular token policy after login (`E403`). Use link/pack/templates until registry succeeds.

**Source zip:** `chameleon-ui/dist-release/chameleon-ui-0.1.9-source.zip` via `pnpm pack:source`. Or `git checkout v0.1.9`.

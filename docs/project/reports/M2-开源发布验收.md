## 6. 版本与发布约定

- 当前包版本 `0.0.0`。首发 git tag：`v0.1.0`（手动 tag，不用 Changesets）。
- `pnpm publish -r` 只发非 private 包；`workspace:*` 由 pnpm 在 publish 时改成版本号。
- **本仓不执行 npm publish。** `publish:check` 只打印计划（10 个可发包）。
- 官方 8 套致敬主题以免费 SKU 出货；社区包可以免费或付费。维护者冻结 v0.1.0 之前不 npm publish。

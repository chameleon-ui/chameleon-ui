# 0.3.0 发布说明（2026-08-16）

本文是 0.3.0 的完整发布记录。CHANGELOG 里有同内容的精简条目。

## 版本状态

- 全部 workspace 包为 `0.3.0`，包括 `toolings/` 下三个私有包（eslint-config、stylelint-config、tsconfig）。
- 未发布 npm，原因与 0.2.0 相同：账号 2FA / granular token 策略，`npm publish` 返回 E403。
- git tag 尚未创建。本切割提交后打 `v0.3.0`；目前仓库最新标签仍是 `v0.1.9`。
- 外部接入方式不变：`scripts/pack-external.mjs` 打伞包 tarball、`scripts/link-external.mjs` 做 `npm link`、或直接用 `templates/external-vite-react` / `templates/external-vite-vue`。

## 破坏性变更

### 1. 组件包改名

`@chameleon-ui/components` 改为 `@chameleon-ui/components-react`，目录同步为 `packages/components-react`，与 `components-vue` 对称。

经由伞包（`@chameleon-ui/react` / `@chameleon-ui/vue`）消费的代码不受影响。只有直接从 `@chameleon-ui/components/*` 引子路径（如 `/css`、`/contracts/<slug>`、`/button`）的消费者需要改写法。

### 2. 主题 id 改名

| 旧 id | 新 id |
| :--- | :--- |
| `line` | `linear` |
| `silver-arrow` | `mercedes` |
| `stuttgart` | `porsche` |
| `corsa` | `ferrari` |
| `cupertino` | `apple` |
| `siren` | `tiktok` |
| `ant-blue` | `alipay` |
| `wechat` | 不变 |

受影响的写法：`theme="…"` 属性、`@chameleon-ui/themes/<id>/css` 子路径、`data-theme="…"` 选择器、MCP / CLI 的主题参数。旧 id 没有保留别名。

## 深浅色手动切换

双端 `ThemeProvider` 新增 `colorScheme?: "dark" | "light"`，设置时写 `documentElement.dataset.colorScheme`，卸载或改回时移除。

主题侧的备选方案是一个新文件：深色优先的主题写 `tokens.light.json`，浅色优先的主题写 `tokens.dark.json`；都是 `$extends` 基础 token，只覆盖色板、文字和阴影。构建时分别产出 `:root[data-color-scheme="light"]` / `:root[data-color-scheme="dark"]` 变量块。必须 `$extends`，否则备选块里没覆盖的 token 会掉回 core 默认值。

不传 `colorScheme` 就用主题默认。主题在 `meta.json` 里声明 `colorSchemes` 和 `defaultColorScheme`；linear 默认深色，apple 默认浅色。

## linear 旗舰：按 Linear 真实 CSS 重做

旧版 linear（当时的 `line`）是凭观感调的。这次直接从 Linear 的两份官方 CSS 里取值：营销站的 `Button.css`，以及 app 加载页（`linear.app/login`）的内联样式。字体和图标不复刻，这是有意决定。

| 项 | 取值 | 出处 |
| :--- | :--- | :--- |
| 主画布 | `#121213` | app `--bg-base-color-dark` |
| 侧栏 / 外壳 | `#09090a`（比画布深） | app `--bg-sidebar-dark` |
| 抬升面 | `#1c1c1d` | app 加载页 secondary bg |
| 品牌色 | `#5e6ad2`，只给 CTA 和激活态 | Linear 品牌靛蓝 |
| 按钮形状 | 药丸（`9999px`） | Button.css `--button-corner-radius: var(--radius-rounded)` |
| 按钮 hover | `filter: brightness(1.15)` | Button.css primary hover |
| 按压 | `transform: scale(.97)` | Button.css `:active` |
| 禁用 | `opacity .5` | Button.css `:disabled` |
| 焦点环 | `2px solid #7180ff`，偏移 3px | app 加载页 |
| 缓动 | ease-out-quad `cubic-bezier(0.25,0.46,0.45,0.94)` 等三条 | Button.css / 加载页 |
| 动效时长 | 100 / 160 / 1200ms | Button.css `.16s` |
| 次按钮 | 半透明底 + 四层内外阴影环 + `blur(4px)` | Button.css variant-secondary |

浅色方案同样按 app 实测值：画布 `#f9f9fa`、侧栏 `#efeff0`、边框 `#e2e2e2`、正文 `#23252a`。

这些值不再是"差不多就行"。`packages/themes/scripts/test-themes.mjs` 对每条关键值写了断言（圆角、灰阶、`scale(.97)`、`brightness(1.15)`、药丸、焦点环、浅色覆盖块），另有逐字节回归基线（`test-themes-regression.mjs`）。改坏任何一条，测试直接红。

两点说明：

- "面板禁玻璃"的护栏收窄到了表面组件（dialog、nav、card、shell）。次按钮上的 `blur(4px)` 是 Linear 的真实实现，不算违规。
- 组件级观感尚未做人眼验收。CSS 值可以对齐，"像不像"要打开浏览器看。`recognition_rate` 保持 `null`。

## apple 旗舰：按 HIG 与 iOS 系统色板重做

旧版 apple（当时的 `cupertino`）是一层轻量覆盖：圆角偏大、加了毛玻璃，但色板、字级、动效都没对着 Apple 的规范走。这次以 Human Interface Guidelines 和 iOS 系统色板为准重做。字体（SF Pro）和图标（SF Symbols）不复刻，字体栈回退到平台系统字体，这是有意决定。

| 项 | 浅色 | 深色 |
| :--- | :--- | :--- |
| 品牌蓝（systemBlue） | `#007AFF` | `#0A84FF` |
| 主文本（label） | `#000000` | `#FFFFFF` |
| 次文本（secondaryLabel） | `rgba(60,60,67,0.6)` | `rgba(235,235,245,0.6)` |
| 基底（systemBackground） | `#FFFFFF` | `#000000` |
| 分组画布（systemGroupedBackground） | `#F2F2F7` | `#1C1C1E` |
| 抬升面 | `#FFFFFF` | `#2C2C2E` |
| 分隔线（separator） | `rgba(60,60,67,0.29)` | `rgba(84,84,88,0.6)` |
| 危险色（systemRed） | `#FF3B30` | `#FF453A` |
| 填充梯度（systemFill 系列） | `rgba(120,120,128,0.2…0.08)` 四档 | `rgba(120,120,128,0.36…0.18)` 四档 |

结构与交互决策：

- **浅色优先**。`tokens.json` 是浅色基础版，深色写在 `tokens.dark.json`（`$extends` 翻转），构建脚本为此新增了对称的 dark 分支。`meta.json` 声明 `defaultColorScheme: "light"`。
- **材质保留**。与 linear 的"全面禁玻璃"相反，apple 的外壳（导航栏、工具栏、TabBar、侧栏）全部使用 bar 材质：`saturate(180%) blur(20px)`；弹层用厚材质 `blur(40px)`。`prefers-reduced-transparency` 时降级为不透明。
- **药丸按钮**。App Store「获取」按钮和 Apple 官网 CTA 都是胶囊形，按钮圆角统一 `9999px`；hover 只提亮 8%（`brightness(1.08)`），按压变暗（`brightness(0.92)`），不做夸张的缩放。
- **选中用填充色**。侧栏选中态用 systemFill 灰阶而不是品牌蓝，这是 iOS 设置类界面的真实做法；TabBar 激活项才用品牌蓝着色。
- **圆角阶梯** 8 / 10 / 14 / 20px：小控件、分组列表卡片、alert、sheet 各一档。
- **字级按 Dynamic Type 默认档**：正文 17px（行高 22/17 ≈ 1.29）、Title3 20px、Title1 28px、Large Title 34px。不做负字距。
- **动效** 300ms UIKit ease-in-out（`cubic-bezier(0.42,0,0.58,1)`），无回弹。
- **卡片无阴影**，靠分组画布的灰度差分层；弹层用大而软的阴影（`0 12px 40px rgba(0,0,0,0.12)`）。
- **焦点**是 accent 色的柔和光晕（4px、35% 透明度），不是硬描边。

测试断言与 linear 同规格：色板两套（浅/深）、材质开关、字级、圆角、药丸、hover/按压曲线全部锁进 `test-themes.mjs`，另有逐字节回归基线。

同样的诚实边界：值级是 1:1 对齐的，但"一眼看上去像不像 Apple"还需要人眼在浏览器里验收；HIG 本身不公布具体色值（文档明示仅供参考），这里采用 iOS 公认值。`recognition_rate` 保持 `null`。

## MaskPaintCanvas 缩放

React 和 Vue 同步落地，API 一致：

- props：`zoom`、`minZoom`、`maxZoom`、`wheelZoom`
- 句柄：`zoomIn`、`zoomOut`、`resetZoom`、`setZoom`、`getZoom`
- 事件：`zoomChange`（React `onZoomChange`）
- 平移：中键拖拽，或按住 Space 拖拽
- 实现用纯 translate，不用 scale 变换，避免画笔坐标系失真

## 21 语言补齐

审计发现 116 个组件里 95 个存在英文占位：Phase 6 脚手架只翻了 en/zh-CN/de/ar，其余 17 个 locale 直接镜像英文；本轮新增的几个组件连 zh-CN/de/ar 也没翻。

这轮人工翻译回填了 2,493 条（146 条去重源串 × 20 个 locale），全部短 UI 标签按各语言软件本地化惯例处理。剩余 64 处与英文同形的值逐一核对过，都是外来词或本来同词（如法语的 Menu、西班牙语的 Error），登记在审计脚本的白名单里。

`packages/i18n/scripts/audit-locales.mjs` 是这轮新增的常驻审计脚本，查三件事：21 个 locale 文件是否齐全、键是否和 en.json 对齐、非英文值是否镜像英文。`pnpm --filter @chameleon-ui/i18n audit:locales` 可重复执行。

## 外壳与布局（本轮早些时候落地）

- `NavigationBar` 公开改名为 `NavigationTitle`（slug `navigation-title`），和负责目的地的 `Navigation` 区分开。旧名保留为 deprecated 别名，CSS 过渡期双类名。
- 侧栏品牌头 `TitleBar`、账号卡 `NavAccountCard`（Navigation 的 `header` / `footer` 槽位，仅侧栏形态显示）；AppShell 一等 `Footer`，`footerPlacement` 默认 `auto`。
- WorkspaceSplit 通过内部 `__frame` 做容器查询变形，可选 `tools` 面板；`scrollMode` 默认 `shell`，AppShell `__main` 是唯一滚动属主。
- 三端一体：AppShell 全 bleed；紧凑宽度锁定为 TabBar，手机上不会再残留侧轨；三栏需要主区 ≥80rem。
- 棋盘格（CheckerboardSurface / ImageCompare / MaskPaintCanvas）统一到 `--cu-checkerboard-a/b` token；linear 在深色画布上用 30%/6%（strong 46%/5%）。
- Stack 的 `align="start"` 现在真的生效（之前卡在 stretch）；新增 `ButtonGroup` 做分段工具开关。

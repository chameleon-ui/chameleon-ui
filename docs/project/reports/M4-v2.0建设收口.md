## 1. 摘要

主题市场可浏览/安装官方免费致敬主题与社区主题；纪律包 `community-focus-first`（`type=registry:rules`）经同一市场列出并只经 `install-core` 写盘（`source=market`）。官方 8 套以免费 SKU 上架，不得作为付费 SKU；社区包可以免费或付费。MCP Apps 按阶段卡决策树选择 **适配 POC**（SEP-1865 Final），独立包 `@chameleon-ui/adapter-mcp-apps`，不进 L1。文档站 21 语 chrome ICU 骨架与缺口表已落。VPAT **status=draft**。性能/a11y 审计指向既有 `perf:size` / VR / `perf:lhci` 桩；R1–R3 书面遗留。北极星看板只读消费 `bench.*` / `telemetry.*`。移交说明书含权限、端口、密钥轮转占位、日历与遗留。`ci:phase4` 含 `ci:phase3`，`phase4:gates` 含 market-service 与纪律包测试。

**未做（明确禁止伪造）**：编造 Lighthouse；VPAT certified / 律所意见书；宣称盲测 80%；npm publish；把营销页写成 21 语已完成；付费鉴权 SDK；运营签收。

## 4. MCP Apps

决策：**adapt**。理由：SEP-1865 Final（2026-01-26），扩展 `io.modelcontextprotocol/ui`，映射面小，可复用 A2UI 的 L3/L4 + install-core 模式。

诚实边界：POC 映射 + HTML 模板 demo。**未**挂到 `mcp-server` 的 `ui://` 资源；**未**做 Claude/ChatGPT/VS Code 宿主认证；双向 JSON-RPC **未**接线。禁止写成「已适配生产宿主」。

## apple 旗舰：按 HIG 与 iOS 系统色板重做

旧版 apple（0.3.0 之前的 `cupertino`）是一层轻量覆盖：圆角偏大、加了毛玻璃，但色板、字级、动效都没对着 Apple 的规范走。这次以 Human Interface Guidelines（developer.apple.com/design/human-interface-guidelines）和 iOS 系统色板为准重做。字体（SF Pro）和图标（SF Symbols）不复刻，字体栈回退到平台系统字体，这是有意决定。

| 项 | 浅色 | 深色 |
| :--- | :--- | :--- |
| 品牌蓝（systemBlue） | `#007AFF` | `#0A84FF` |
| 主文本（label） | `#000000` | `#FFFFFF` |
| 次文本（secondaryLabel） | `rgba(60,60,67,0.6)` | `rgba(235,235,245,0.6)` |
| 基底（systemBackground） | `#FFFFFF` | `#000000` |
| 分组画布（systemGroupedBackground） | `#F2F2F7` | `#1C1C1E` |
| 抬升面 | `#FFFFFF` | `#2C2C2E` |
| 分隔线（separator） | `rgba(60,60,67,0.29)` | `rgba(84,84,88,0.6)` |
| 危险色（systemRed） | `#FF3B30` | `#FF453A` |
| 填充梯度（systemFill 系列） | `rgba(120,120,128,0.2…0.08)` 四档 | `rgba(120,120,128,0.36…0.18)` 四档 |

结构与交互决策：

- **浅色优先**。`tokens.json` 是浅色基础版，深色写在 `tokens.dark.json`（`$extends` 翻转）。`meta.json` 声明 `colorSchemes: ["light", "dark"]`、`defaultColorScheme: "light"`；`ThemeProvider colorScheme="dark"` 手动切深。
- **材质保留**。与 linear 的"全面禁玻璃"相反，apple 的外壳（导航栏、工具栏、TabBar、侧栏）全部使用 bar 材质：`saturate(180%) blur(20px)`；弹层用厚材质 `blur(40px)`。`prefers-reduced-transparency` 时降级为不透明。
- **药丸按钮**。App Store「获取」按钮和 Apple 官网 CTA 都是胶囊形，按钮圆角统一 `9999px`；hover 只提亮 8%（`brightness(1.08)`），按压变暗（`brightness(0.92)`），不做夸张的缩放。
- **选中用填充色**。侧栏选中态用 systemFill 灰阶而不是品牌蓝，这是 iOS 设置类界面的真实做法；TabBar 激活项才用品牌蓝着色。
- **圆角阶梯** 8 / 10 / 14 / 20px：小控件、分组列表卡片、alert、sheet 各一档。
- **字级按 Dynamic Type 默认档**：正文 17px（行高 22/17 ≈ 1.29）、Title3 20px、Title1 28px、Large Title 34px。不做负字距。
- **动效** 300ms UIKit ease-in-out（`cubic-bezier(0.42,0,0.58,1)`），无回弹。
- **卡片无阴影**，靠分组画布的灰度差分层；弹层用大而软的阴影（`0 12px 40px rgba(0,0,0,0.12)`）。
- **焦点**是 accent 色的柔和光晕（4px、35% 透明度），不是硬描边。

测试断言与 linear 同规格：浅/深两套色板、材质开关、字级、圆角阶梯、药丸、hover/按压曲线、无 SF Pro 引用，全部锁进 `packages/themes/scripts/test-themes.mjs` 的 apple 断言块；`test-themes-regression.mjs` 的逐字节基线已随本次评审过的变更重写。

## tokens.dark.json：浅色优先主题的深色方案

0.3.0 的深浅色切换只支持深色优先的主题（`tokens.light.json` 翻浅色）。apple 是浅色优先，方向相反，因此构建脚本新增了对称分支：`tokens.dark.json` 经 `$extends` 解析后编译成 `:root[data-color-scheme="dark"]` 变量块，追加在基础变量之后。规则与 light 分支一致：必须 `$extends` 基础 token，否则没覆盖的 token 会掉回 core 默认值。apple 是第一个使用者。

## 诚实边界

- `recognition_rate = null`。apple 旗舰的值级是 1:1 对齐的，但"一眼看上去像不像 Apple"还需要人眼在浏览器里验收；HIG 本身不公布具体色值（文档明示仅供参考），这里采用 iOS 公认值。

- 6 套致敬主题是覆盖层，打磨程度不如 linear / apple 两套旗舰。
